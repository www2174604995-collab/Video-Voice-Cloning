# 使用教程

从零到出片，按顺序做一遍即可。

## 一、安装

### 本地 Windows（上手最快）

```bat
git clone https://github.com/www2174604995-collab/Video-Voice-Cloning.git
cd Video-Voice-Cloning
install.bat        :: 装依赖 + 下模型，约 20 分钟
start.bat          :: 启动，浏览器打开 http://127.0.0.1:8765
```

没有 NVIDIA 显卡也能跑（CPU），只是配音慢（每句 7~9 秒）。

### 云 GPU（效果最好）

见 [`云GPU部署.md`](云GPU部署.md)。一句话：

```bash
git clone https://github.com/www2174604995-collab/Video-Voice-Cloning.git bilisimul
cd bilisimul && bash scripts/setup_linux.sh
TTS=voxcpm bash scripts/run_server.sh
```

然后在本地建隧道：`ssh -L 8765:127.0.0.1:8765 -p <端口> root@<主机>`，
浏览器访问 `http://127.0.0.1:8765/`。

## 二、B 站实时同传

1. Chrome 打开 `chrome://extensions` → 右上角打开 **开发者模式**
2. 点 **加载已解压的扩展程序** → 选项目里的 `extension/` 目录
3. 打开任意 B 站视频，点工具栏的扩展图标 → 面板出现
4. 选目标语言 → 点 **开始同传**（首次需要点一次图标授权）

面板上会显示：`采集 3/秒 · 播放 12 · 丢 0 · 延迟 2.4s`。

> 第一次点开始如果没声音，刷新页面再点一次——Chrome 要求用户手势才能抓音频。

## 三、上传视频换声

### 网页版

1. 打开 `http://127.0.0.1:8765/dub`
2. 拖入视频、拖入参考音（10~60 秒，只有一个人说话最好）
3. 语言选「只换音色」或「翻译成中文」
NaN

大文件建议用「服务器文件」标签：先用 JupyterLab 把视频传到 `data/input/`，再在页面上填文件名——不经过隧道，快很多。

### 命令行

```bash
python tools/dub_video.py \
  --video data/input/course.mp4 \
  --ref   data/input/my_voice.wav \
  --target zh \
  --tts voxcpm \
  --bg 0 \
  --out data/out/course_dubbed.mp4
```

| 参数 | 作用 |
|---|---|
| `--target same` | 只换音色，保留原语言 |
| `--target zh` | 翻译成中文 |
| `--bg 0.1` | 保留 10% 原声当背景（有 BGM 时用） |
| `--srt subs.srt` | 用字幕文本，跳过识别和翻译 |
| `--tts indextts` | 换引擎（中文更稳，音色差一点） |

## 四、视频有字幕怎么办

**字幕是最准的文本来源**，有就一定要用。

### 外挂字幕（.srt / .ass）

```bash
python tools/dub_video.py --video in.mp4 --srt in.srt --ref voice.wav --target zh --out out.mp4
```

### 内嵌字幕轨

```bash
ffmpeg -i in.mkv -map 0:s:0 subs.srt
```

### 硬字幕（烧在画面上）

```bash
python tools/ocr_subs.py --video in.mp4 --out subs.srt
```

9 分钟视频约 8~10 分钟（CPU）。产出后**先看一眼**：

```bash
head -30 subs.srt
```

如果有水印残渣（`bilibili x3c`、`ISk-I`），调 `--band`（裁剪区域）或 `--min-score`（置信度门槛）。

## 五、参数怎么调

`server/config.yaml`：

```yaml
tts: voxcpm              # voxcpm 最像；indextts 最稳
ref_trim: 0              # 0 = 用完整参考音（截短会掉相似度）
voxcpm_mode: ref         # 纯参考音模式，跨语种最稳
voxcpm_timesteps: 12     # 12 与 20 音色无差别，12 更快
dub_candidates: 2        # 每句生成几个候选，越多越稳越慢
sub_merge_sec: 14        # 相邻字幕合并成整句（自然度关键）
dub_max_speedup: 1.0     # 1.0 = 不变速
repair_tts: indextts     # 校验失败的句子用它重做
```

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 声音不像 | 参考音换成 10~60 秒的干净单人音频；确认 `ref_trim: 0` |
| 偶尔胡言乱语 | 保持 `dub_check: true`（逐句语音回听校验） |
| 句子被切断 | `dub_max_speedup: 1.0`，让句子自然溢出后淡出 |
| 音量忽大忽小 | 已内置逐句响度归一 + 软限幅；仍有问题可调 `dub_candidates` 让模型多试几次 |
| 英文被跳过 | 用新版 OCR（保留英文），或手动在 SRT 里补 |
| 显存不足 | 降 `asr_model` 到 `medium`，或关掉 `repair_tts` |
| B 站没声音 | 刷新页面，重新点「开始同传」（Chrome 手势限制） |

## 七、合规

克隆他人声音需获得授权；训练/使用自己的声音没有限制。
